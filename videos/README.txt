# CÓMO COLOCAR TU VIDEO DE PORTADA (HERO VIDEO) - MERLO AVENTURA

Para que el video se reproduzca automáticamente en la portada de la web:

1. Guardá tu archivo de video con el nombre exacto:
   hero.mp4

2. Colocalo dentro de esta misma carpeta:
   /Users/valen/.gemini/antigravity/scratch/merlo-aventura/static/videos/hero.mp4

¡Y listo! La web ya está 100% configurada para detectarlo y reproducirlo automáticamente en bucle (loop, muted, autoplay, playsinline) con controles de sonido (desmutear) y pausa/reproducción.

Formatos recomendados:
- MP4 (códec H.264 o AAC)
- Resolución: 1080p o 720p optimizado para web (idealmente menos de 30-50 MB para carga ultrarrápida en móviles)
